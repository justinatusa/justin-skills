# justin-skills

Justin 收藏的 Agent Skills。首页只做索引；正文在各自目录的 `SKILL.md`。

装法：把某个 skill 目录拷进你的 skills 路径，或把 `SKILL.md` 当提示词用。同类写法可参考 [mattpocock/skills](https://github.com/mattpocock/skills)、[github/awesome-copilot](https://github.com/github/awesome-copilot) 的 skills 表。

## Skills

| Skill | 解决啥 | 示意 |
|-------|--------|------|
| [project-architecture-map](skills/project-architecture-map/) | 功能迭代太快、架构跟不上 / AI 写码变黑箱时，按真实代码画出可交互的架构与流程地图（缩放、点步骤、看流向），而不是又一份静态 wiki。相对 deepwiki 更偏可视化。[来源](https://x.com/LinearUncle/status/2105506429788422409) · [灵感](https://x.com/robinebers/status/2105309987983745060) | <img src="skills/project-architecture-map/assets/linearuncle-demo-1.jpg" width="320" alt="架构地图示意" /> |
